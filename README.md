# Компонент карточки товара
https://marussia1996.github.io/teaboomTest/

## Запуск локально

1. Скачайте проект или клонируйте репозиторий:

   ```bash
   git clone https://github.com/marussia1996/teaboomTest.git
   ```

2. Откройте папку проекта и файл `index.html` в браузере.

Установка зависимостей и сборка не нужны. Для загрузки фотографии товара требуется интернет.
